# Шрифты

DejaVu 2.37 — свободные шрифты с полным покрытием кириллицы, включая казахские
буквы (Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, Һ, І). Лежат в репозитории, чтобы документы
собирались одинаково на любой машине и на раннере CI, где системных шрифтов
с кириллицей может не быть.

- `DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` — основной текст документов
- `DejaVuSansCondensed-Bold.ttf` — цифры стартовых номеров (узкие, влезает больше)
- `DejaVuSerif-Bold.ttf` — заголовки грамот

Лицензия — `LICENSE-DejaVu.txt`, источник — <https://dejavu-fonts.github.io/>.
