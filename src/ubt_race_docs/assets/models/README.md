# Модели

`trophy.scad` — параметрическая модель кубка: разделочный велосипед
на подставке. Печатается двумя деталями, см. [docs/print.md](../../../../docs/print.md).

`ubt-logo.svg` и `giant-logo.svg` — векторные контуры логотипов для гравировки.
Получены трассировкой растровых оригиналов (`potrace -s -W 100mm`), поэтому
гравировка остаётся чёткой при любом размере. Ширина обоих контуров — 100
единиц, высота у каждого своя и задана в модели параметрами `*_source_height`:
после пересборки контура её нужно поправить, иначе логотип растянет.
