# Картинки

`ubt-logo.png` — логотип Universal Bicycle Team, 180×180. Взят из статики
сайта команды (`cycling_site/static/apple-touch-icon.png`). Стоит на линии
сгиба стартового номера и в шапке грамоты.

Фон у файла белый, не прозрачный, — на белой бумаге это незаметно. Если
логотип поменяется, достаточно положить сюда новый файл с тем же именем.
