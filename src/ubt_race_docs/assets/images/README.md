# Картинки

`ubt-logo.png` — логотип Universal Bicycle Team, 800×800. Пересобран из
актуального одноцветного оригинала команды (`logo/1000289755.png`, 1772×1772,
фон уже прозрачный): обрезан по контуру и вписан в квадрат — `draw_logo`
рисует его квадратом и иначе исказил бы пропорции.
Размер выбран под печать: водяной знак на грамоте выходит 226 dpi, логотип
на стартовом номере — 847 dpi. Иконки из статики сайта (180×180) для этого
не хватало: водяной знак печатался бы лесенкой.

Логотип стоит на линии сгиба стартового номера — там он ложится спереди
на подседельную трубу — и бледным водяным знаком по центру грамоты.

Фон обязан быть прозрачным: на кремовом листе грамоты белый квадрат вокруг
логотипа было бы видно. Если логотип поменяется снова, кладите сюда новый файл
с тем же именем — с прозрачным фоном и стороной не меньше 800 пикселей — и
не забудьте пересобрать `../models/ubt-logo.svg` для гравировки.

`giant-logo.png` — логотип Giant, партнёра гонки, 1600×308. Пересобран из
`GIANT/GiantLogo.jpeg`, белый фон вырезан в прозрачность. Стоит на стартовых
номерах — в той части, что обнимает подседельную трубу, — и в подвале грамоты.
