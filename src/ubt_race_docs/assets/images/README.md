# Картинки

`ubt-logo.png` — логотип Universal Bicycle Team, 800×800. Пересобран из
исходника сайта команды (`media/original_images/prod_logo.jpg`, 1034×1034).
Размер выбран под печать: водяной знак на грамоте выходит 226 dpi, логотип
на стартовом номере — 847 dpi. Иконки из статики сайта (180×180) для этого
не хватало: водяной знак печатался бы лесенкой.

Логотип стоит на линии сгиба стартового номера — там он ложится спереди
на подседельную трубу — и бледным водяным знаком по центру грамоты.

Фон у файла белый, не прозрачный, — на белой бумаге это незаметно. Если
логотип поменяется, достаточно положить сюда новый файл с тем же именем.
