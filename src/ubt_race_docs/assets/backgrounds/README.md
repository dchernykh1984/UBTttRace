# Фон грамоты

По умолчанию фон грамоты рисуется кодом — кремовый лист, оранжевые полосы
командных цветов, рамка и логотип водяным знаком. Ничего класть сюда не нужно.

Чтобы получить другой вариант грамоты, положите в этот каталог картинку
`certificate.png` (или `.jpg`) — она станет фоном вместо нарисованного,
на весь лист, а весь текст ляжет поверх неё. Заменили файл — поменялась
грамота, править код не надо.

Что важно для печати:

- пропорции A4 (210×297 мм), вертикально;
- 300 dpi — это 2480×3508 пикселей, меньше 150 dpi будет мылить;
- светлая середина, иначе поверх неё не прочитать текст;
- офисный принтер не печатает до самого края, поэтому важное в картинке
  держите в 6 мм от границ.

Разово, не трогая этот каталог, картинку можно подсунуть и так:

```bash
uv run ubt-race-docs certificates --background ~/Pictures/фон.png --out dist
```
