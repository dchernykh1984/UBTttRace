# Комплект материалов

| Что | Модуль | Файл на выходе |
| --- | --- | --- |
| Стартовые номера 1–300 | `bibs.py` | `bib-numbers-1-300.pdf` |
| Грамоты | `certificates.py` | `certificates.pdf` |
| Расписки об ответственности | `waivers.py` | `waiver-adult.pdf`, `waiver-minor.pdf` |
| Таблица призовых | `workbook.py` | `prize-money.xlsx` |
| Карта трассы для партнёров | `route_map.py` | `map.png` |
| Кубки | `trophies.py` + `assets/models/trophy.scad` | шесть `trophy-*.stl` |

Сборка: `make build` (всё, кроме кубков), `make kit` (плюс кубки), или
поштучно — `make bibs`, `make certificates`, `make waivers`, `make workbook`,
`make map`, `make models`. То же самое напрямую: `uv run ubt-race-docs all
--with-trophies --out dist`.

## Смотреть глазами обязательно

Тесты ловят числа, но не композицию. После правки любого печатного документа
отрисуйте страницу и посмотрите на неё:

```bash
uv run --with pymupdf python -c "
import pymupdf; pymupdf.open('dist/certificates.pdf')[0].get_pixmap(dpi=110).save('/tmp/page.png')"
```

Так были пойманы наезжающие подписи на карте, невидимый водяной знак на
грамоте и логотип, который на синей плашке сливался с фоном.

## Что важно помнить про каждый документ

**Номера.** A4 поперёк, две полосы на лист, режутся вдоль. Полоса
оборачивается серединой вокруг подседельной трубы, хвосты склеиваются, номер
читается с обеих сторон. Поэтому в середине полосы зарезервировано
`wrap_allowance` (55 мм на каждый хвост — полупериметр трубы), и трёхзначные
цифры не должны подходить к центру ближе 5 см. Логотип UBT стоит на линии
сгиба, логотип Giant — в зоне обхвата с обеих сторон, повёрнут верхом вперёд.

**Грамоты.** 10 наградных групп (абсолют и четыре возрастные у каждого пола)
× 3 места + 3 запасных = 33 страницы. Главный судья впечатан. Фон рисуется
кодом в `background.py`; водяной знак опущен ниже центра листа, чтобы не
попадать под крупную строку с местом, и его прозрачность (0.2) подобрана
так, чтобы на бумаге знак не пропал, — на печати светлые тона садятся.
Фон можно подменить картинкой, положив её в `assets/backgrounds/`.

**Расписки.** Две формы: для взрослого и для законного представителя
несовершеннолетнего. Это шаблон организатора, а не юридический документ,
и говорить об этом честно.

**Карта.** Схема, а не топография: направление, длина, разворот и сёла стоят
верно относительно трассы, контуры дорог и речка нарисованы приблизительно.
Профиль восстановлен по треку и подогнан так, чтобы суммарный набор совпал
с 55 м. Названия сёл — русской транслитерацией, все в `LANDMARKS`.

## Двуязычность

Каждая надпись двуязычна: русский и казахский идут парой через `Bilingual`
в `race.py`. Новый казахский текст должен вычитать носитель языка — если
добавляете строку, скажите об этом вслух.
