# UBT TT — печатные материалы гонки

Генератор всего, что печатается к контрольной тренировке с раздельным стартом
«День рождения UBT» (4 октября 2026, село Кырбалтабай под Алматы): стартовые
номера, грамоты, расписки об ответственности, таблица призовых, STL кубков
и карта трассы для партнёров. Python 3.11–3.13, uv, reportlab, openpyxl,
Pillow, OpenSCAD. Релизы собирает GitHub Actions.

## Правила, которые не обсуждаются

- **Коммит — одна строка.** Без тела, без `Co-Authored-By`, без упоминания
  Claude или соавторства. На это стоит хук в `.claude/settings.json`.
- **В репозитории только код.** PDF, XLSX, STL и PNG собираются из исходников
  и прикладываются к релизу — коммитить их нельзя.
- **Данные гонки живут в одном месте** — [race.py](src/ubt_race_docs/race.py).
  Название, дата, место, категории, денежные правила берутся оттуда, а не
  вписываются в шаблоны руками.
- **Казахский текст не выдумываем.** Существующие строки перенесены с сайта
  команды; новые должен вычитать носитель языка, и об этом надо сказать вслух.
- **Геометрия проверяется тестом, а не на глаз.** Всё, что должно поместиться
  на лист, на колесо или на подставку, проверяется расчётом в `tests/`.

## Где детали

| Скилл | О чём |
| --- | --- |
| `shipping-changes` | ветки, коммиты, пулл-реквесты, CI, релизы через release-please |
| `print-kit` | из чего состоит комплект, как собрать локально и как посмотреть результат |
| `trophy-model` | параметрическая модель кубка в OpenSCAD и печать |
| `prize-money` | правила призовых и таблица, которая считается в Numbers |
| `brand-assets` | логотипы UBT и Giant, откуда берутся и как пересобираются |
| `team-site` | сайт команды: отдельный репозиторий, откуда приходят данные гонки |

## Быстрые факты

- Зависимости и запуск: `make install`, дальше `make build` (все документы),
  `make kit` (плюс кубки), `make test`, `make lint`, `make typecheck`.
  Результат складывается в `dist/`.
- Проверки перед коммитом идут сами: pre-commit гоняет ruff, mypy и гигиену
  файлов, а `conventional-pre-commit` проверяет тип коммита.
- Тесты: `uv run pytest` — около 240 штук, один пропускается без OpenSCAD.
- Версию проекту проставляет release-please; в `pyproject.toml` она
  `dynamic`, иначе `uv.lock` устаревал бы на каждом релизном PR.
